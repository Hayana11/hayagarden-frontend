# 自由时间唤醒

normal、morning、nightwatch、self_trigger 共用自由时间提示，保留各自的开场和收尾。报纸与只读观察继续附在末尾。
主轮允许 5 次实际放行的工具调用，前置观察另有 3 次。原生工具发现也消耗一次。
PreToolUse 在执行前原子扣减；事件记录与执行方的复核不重复扣减。同一轮冷热路径共享额度。
唤醒不能签发 ledger.write，灯光控制继续保留。普通聊天仍可记账。

开口时照常投递。沉默时第一行写 [[SILENT]]，做过事可在第二行写 [[ACTIVITY]] 标题｜一句话。
投递事务同时保存活动；静默不产生聊天消息。标题和摘要分别截到 16、40 字。
GET /api/wake/activity 返回 items，按北京时间和 wake_run_id 倒序。since 为含起点的时间，
before 和 before_id 为不含端点的上一页游标，limit 默认 50、最大 200；silent=1 仅取沉默活动。
工具详情只保存名称、是否成功与时间，接口只返回名称。
