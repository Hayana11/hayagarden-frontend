填入订阅 token

在自己电脑上运行 claude setup-token（需要已订阅的 claude.ai 账号登录浏览器授权），把生成的 token 粘贴到这里。token 将写入 .env 并重启网关。
⚠️ 不要把这个 token 给任何其他人或网站。
